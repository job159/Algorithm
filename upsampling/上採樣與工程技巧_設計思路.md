# 上採樣 / 重取樣 與工程技巧：設計思路 與 一步一步的計算邏輯（白話詳解）

> **一句話總結**：對「帶限訊號」來說，取樣點之間的值**早就被決定了**——
> 上採樣是把它們**算回來**（插零 → 低通 → ×L），降採樣是先把**裝不下的高頻砍掉**再丟點（低通 → 每 M 取一）。

> **時間 / 座標一定要對齊**（群延遲、半像素），**沒量到就老實說沒量到**（NaN，不硬插）。

## 一、先搞懂：取樣定理與 Nyquist

取樣 = 每隔 Δt = 1/fs 秒記一個數字。問題是：**中間沒記到的部分，資訊是不是就丟了？**

**取樣定理**的答案：如果訊號裡最高的頻率 **< fs/2**（這個 fs/2 叫 **Nyquist 頻率**），
那麼這些樣本就**完整決定了**整條連續曲線——中間的值可以一分不差地算回來。

```
  慢的波（遠低於 fs/2）：每個週期取很多點，連起來就看得出形狀
      ●     ●
   ●           ●                         ✔ 樣本夠密，曲線唯一確定
 ●───────────────●───────────────●──
                   ●           ●
                      ●     ●

  太快的波（超過 fs/2）：每個週期取不到 2 點
   ●                 ●                   ✘ 這些點也能用一條「慢的假波」穿過去
     ╲    ╱╲    ╱╲  ╱  ...               → 分不出是快波還是慢波 = 混疊（aliasing）
      ╲  ╱  ╲  ╱  ╲╱
       ●        ●
```

白話記法：

> **每個週期至少要取到 2 個點以上**，才分得出「它到底多快」。
> 取樣率 fs 只裝得下 0 ~ fs/2 的頻率；超過的部分不會消失，而是**偽裝**成低頻混進來。

這一句話就是整份文件的地基：
- **上採樣**能做得準，是因為原訊號本來就 < fs/2，中間值「已被決定」。
- **降採樣**一定要先低通，是因為新的 fs/2 變小了，原本合法的高頻會變成假頻。

## 二、上採樣為什麼不能只插零：頻譜鏡像

### 笨方法：插零（zero-stuffing）
要把取樣率變 L 倍，最直覺的做法是在每兩個樣本之間塞 L−1 個 0：

```
原始（L=3）：   x0          x1          x2          x3
插零後：        x0   0   0   x1   0   0   x2   0   0   x3
                ▲           ▲           ▲
                時域：一排尖刺，完全不像原本的平滑曲線
```

### 頻域看發生了什麼

```
原始（取樣率 fs）：能量只在 0 ~ fs/2
   │▇▇▇▅▃
   └──────┬─────────────────────
   0     fs/2

插零 L=3（新取樣率 3fs，新 Nyquist = 1.5 fs）：
   │▇▇▇▅▃      ▃▅▇▇▇▇▇▅▃      ▃▅▇▇
   └──────┬──────────┬──────────┬──
   0     fs/2        fs        1.5fs
     ↑ 真的         ↑ 鏡像（imaging）：本來不存在的高頻
```

插零**沒有改變頻譜的形狀**，只是把「本來在 fs、2fs… 的週期複本」攤開在新的、更寬的頻率軸上。
這些複本就是時域裡那些尖刺的來源。

### 解法：低通 + ×L
1. **低通**：截止在**舊的 Nyquist（fs/2）**，把鏡像全部砍掉 → 只剩第一塊，就是正確的上採樣結果。
   在新取樣率下，這個截止 = 1/L（以新 Nyquist 為 1）→ `design_lowpass_fir(numtaps, cutoff=1/L)`。
2. **×L**：插零後每 L 點只有 1 點有值，**平均值（直流）變成 1/L**；低通的直流增益是 1，
   所以濾完整條曲線只有 1/L 高 → 乘回 L。

> 👉 **上採樣 = 插零 + 低通 + ×L**。
> 線性 / 三次插值其實也是這個公式，只是它們的「低通」比較便宜、比較不乾淨（見下一節）。
> 動畫分頁 A 選「插零+FIR」就能看到 STEP 3a（插零：點掉到 0）→ 3b（核心滑過去把 0 填起來，但只有 1/L 高）→ 3c（×L）。

## 三、各種插值法比較

所有插值法都可以寫成同一個樣子：

> **新點 = Σ（鄰近原始點 × 權重）**，權重來自一個「核心（kernel）」，核心越接近理想低通（sinc），結果越準。

| 方法 | 用幾個鄰居 | 核心形狀 | 本例 RMSE（L=4） | 計算量 / 點 | 過衝 | 適用 |
|---|---|---|---|---|---|---|
| ZOH 零階保持 | 1 | 方塊 | 0.172（最差） | 0 次乘法 | 無 | DAC 輸出、「保持上一個命令」 |
| 線性 | 2 | 三角形 | 0.047 | 2 次 | 無 | 感測器對齊、動畫補間、便宜場合 |
| 三次 Catmull-Rom（a=−0.5） | 4 | 分段三次（兩側有負瓣） | 0.022 | 4 次 | 有（小） | 影像縮放、軌跡平滑 |
| 插零 + 加窗 sinc FIR | numtaps/L（本例 12） | 接近理想低通 | **0.0008** | numtaps/L 次 | 有（被窗壓低） | 音訊、量測、通訊 |
| FFT 頻域補零 | 全部 | 理想 sinc（假設週期） | ≈ 1e-15（週期訊號） | O(N log N) 整段 | 非週期時頭尾環繞 | 週期訊號、離線處理 |

（RMSE 數字來自動畫分頁 A：12 個樣本、L=4、畫面內 45 點；`python resample.py` 用 256 點長訊號測得
ZOH 2.1e-1 > 線性 3.9e-2 > 三次 1.1e-2 > FIR 1.0e-3 > FFT 4e-15，排序一致。）

**怎麼選？**
```
   要極便宜、資料本身就很平滑        → 線性
   影像 / 要曲線平滑（導數連續）     → 三次（記得 clip 過衝）
   要「頻帶內幾乎無失真」            → 插零 + FIR（polyphase 實作）
   訊號是整數週期、可以整段離線算    → FFT 補零
   控制命令、DAC                    → ZOH（本來就是階梯）
```

## 四、跟著手算走一遍：線性與三次插值

用動畫分頁 A 的資料（原始樣本前幾個值）：

| n | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| x[n] | 0.729 | 0.484 | 0.332 | 0.418 | 0.215 | 0.197 | 0.521 |

### 線性：t = 1.75（L=4 的第 7 個新軸點）
- i0 = floor(1.75) = 1，frac = 0.75 → 落在 x[1] 與 x[2] 之間 75% 處
- 權重 = (1 − 0.75, 0.75) = (0.25, 0.75)　← 離 x[2] 比較近，x[2] 權重大

| 用到的點 | 值 | 權重 | 權重 × 值 |
|---|---|---|---|
| x[1] | 0.484 | 0.25 | 0.121 |
| x[2] | 0.332 | 0.75 | 0.249 |
| **合計** | | **1.00** | **0.370**（真值 0.325） |

### 三次（Catmull-Rom）：t = 4.5
核心 W(s)（a = −0.5）：

```
        ⎧  1.5|s|³ − 2.5|s|² + 1            |s| ≤ 1
 W(s) = ⎨ −0.5|s|³ + 2.5|s|² − 4|s| + 2     1 < |s| < 2
        ⎩  0                                其他
```

- i0 = 4、frac = 0.5，用 x[3]、x[4]、x[5]、x[6]，到 t 的距離 = 1.5、0.5、0.5、1.5
- W(1.5) = −0.5·3.375 + 2.5·2.25 − 6 + 2 = **−0.0625**；W(0.5) = 1.5·0.125 − 2.5·0.25 + 1 = **0.5625**

| 用到的點 | 值 | 權重 | 權重 × 值 |
|---|---|---|---|
| x[3] | 0.418 | −0.0625 | −0.026 |
| x[4] | 0.215 | 0.5625 | 0.121 |
| x[5] | 0.197 | 0.5625 | 0.111 |
| x[6] | 0.521 | −0.0625 | −0.033 |
| **合計** | | **1.0000** | **0.173** |

同一點用線性 = (0.215 + 0.197)/2 = 0.206，真值 0.136 → **線性誤差 0.070、三次誤差 0.037**。

**重點觀察：**
- 權重總和永遠是 1 → 常數訊號插值後還是常數（不會整體變亮變暗）。
- 三次的外側兩點權重是**負的**：x[3]、x[6] 都比中間大，負權重把結果往下拉——它「看出」這裡是個谷底。
  這就是三次比線性準的原因，也是它在階躍邊緣會**過衝**的原因。
- 其他 frac 的權重：frac = 0.25 時是 (−0.0703, 0.8672, 0.2266, −0.0234)，總和一樣是 1。

## 五、polyphase：為什麼能省 L 倍

「插零後再濾波」有一個明顯的浪費：插零後的序列 **每 L 個只有 1 個不是 0**，乘 0 是白做工。

```
插零後（L=3）：  x0  0   0   x1  0   0   x2  0   0   x3 ...
核心 h（9 點）：  h0  h1  h2  h3  h4  h5  h6  h7  h8
                 對準某個輸出點時，9 個係數裡只有 3 個碰到非零（每隔 L 一個）
```

所以把 h **按間隔 L 拆成 L 個子濾波器**（群延遲 D = 4）：

| 輸出相位 | 用到的係數 | 子濾波器 |
|---|---|---|
| y[3m]   | h1, h4, h7 | E0 = h[1::3] |
| y[3m+1] | h2, h5, h8 | E1 = h[2::3] |
| y[3m+2] | h0, h3, h6 | E2 = h[0::3] |

每個子濾波器**直接對原始 x 卷積**（在原始取樣率下跑），三路結果交錯排好再 ×L，就得到一模一樣的輸出：

```
         ┌─ E0 ─┐
   x ────┼─ E1 ─┼──► 交錯 y[0], y[1], y[2], y[3], … ──► ×L
         └─ E2 ─┘
```

- **數學上完全等價**：`resample.py` 自我測試比對 `upsample_fir`（polyphase）與 `upsample_fir_direct`（真的插零再卷積），最大差 4e-16。
- **省多少**：每個輸出點從 numtaps 次乘法降到 numtaps/L 次，**省 L 倍**；也不用配置 L 倍長的插零陣列。
- **彩蛋**：截止 = 1/L 的 sinc 在 L 的倍數位置剛好是 0，所以 E0 = [≈0, 1/L, ≈0] → y[3m] ≈ x[m]，
  **原始點幾乎原封不動**（動畫 STEP 3b 走到原始點位置時，核心在其他原始點上都是 0）。

> ⚠️ **群延遲**：長度 numtaps 的對稱 FIR 會讓輸出延遲 D = (numtaps−1)/2 個樣本。
> 用奇數長度讓 D 是整數，取 y[n] = v[n + D] 就精確對齊；忘了扣，整條曲線會往右偏。

## 六、降採樣與混疊：手算假頻

### 笨方法：每 M 個取 1 個
直接丟樣本。新取樣率 fs_new = fs/M，新 Nyquist = fs_new/2 變小了——**原本合法的高頻現在裝不下了**。

### 手算：fs = 100 Hz 的 31 Hz 正弦，每 4 個取 1 個
fs_new = 25 Hz、新 Nyquist = 12.5 Hz，31 Hz 超過了。看看留下來的樣本：

| k（第幾個保留點） | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| sin(2π·31·(4k)/100) | 0 | 0.998 | 0.125 | −0.982 | −0.249 | 0.951 |
| sin(2π·**6**·k/25) | 0 | 0.998 | 0.125 | −0.982 | −0.249 | 0.951 |

**一模一樣！** 在 25 Hz 的取樣下，31 Hz 和 6 Hz 的樣本完全分不出來 → 31 Hz 被「折」成 6 Hz 的假頻。

### 公式
> **f_alias = | f − k·fs_new |，k = round(f / fs_new)**

```
   頻率軸（fs_new = 25 Hz）：
   0        12.5       25        37.5
   ├─────────┼─────────┼─────────┤
   │ 看得到  │ 看不到  │ 看不到  │
        6 ◄──────────── 31        31 − 1×25 = 6 Hz
          （以 fs_new 為週期、對 Nyquist 折回）
```

動畫分頁 B 同一個 31 Hz 在不同 M 下的折回位置：

| M | fs_new | 新 Nyquist | k | f_alias |
|---|---|---|---|---|
| 2 | 50 | 25 | 1 | \|31 − 50\| = 19 Hz |
| 3 | 33.33 | 16.67 | 1 | \|31 − 33.33\| = 2.33 Hz（緊貼真的 3 Hz！） |
| 4 | 25 | 12.5 | 1 | \|31 − 25\| = 6 Hz |
| 5 | 20 | 10 | 2 | \|31 − 40\| = 9 Hz |
| 8 | 12.5 | 6.25 | 2 | \|31 − 25\| = 6 Hz |

### 解法：先低通（抗混疊）再取
截止 = 新 Nyquist（cutoff = 1/M）。`resample.py` 自我測試的數字：
fs = 1000 → 250 Hz，訊號 1.0·sin(50 Hz) + 0.8·sin(430 Hz)，430 Hz 折到 |430 − 2×250| = 70 Hz：

| | 50 Hz 振幅 | 70 Hz（假頻）振幅 |
|---|---|---|
| `decimate_naive`（直接取） | 1.000 | **0.800** |
| `decimate`（先低通） | 1.000 | **0.00004** |

> ⚠️ 混疊一旦發生**事後無法修正**：假頻落在合法頻帶內，跟真訊號長得一模一樣。濾波只能在取樣「之前」做。
> （硬體 ADC 前面的類比抗混疊濾波器也是同一個道理。）

## 七、有理數倍 L/M：44.1 kHz → 48 kHz

### 設計思路
1. **約分**：48000 / 44100，gcd = 300 → **L/M = 160/147**。
2. 概念上：上採樣 160 倍（7.056 MHz）→ 低通 → 降採樣 147 倍。
3. **一支低通同時負責兩件事**：去鏡像（截止 1/L）與抗混疊（截止 1/M），取比較嚴的 → **cutoff = 1/max(L, M) = 1/160**。
4. **只算要留下的點**：輸出第 i 點在高取樣率的位置 n = i·M；它落在第 b = (n + D) mod L 個相位，
   只要用子濾波器 h[b], h[b+L], … 對原始 x 做一次內積。

### 省多少？（numtaps = 2·10·160 + 1 = 3201）

| 做法 | 每秒乘法次數 |
|---|---|
| 真的升到 7.056 MHz、全部濾波、再丟掉 146/147 | 7,056,000 × 3201 ≈ **2.3 × 10¹⁰** |
| polyphase：只算 48000 個輸出，每個用 ⌈3201/160⌉ = 21 個係數 | 48,000 × 21 ≈ **1.0 × 10⁶** |

差了兩萬多倍。輸出長度 = ⌈N·L/M⌉：441 點 → 480 點、4410 點 → 4800 點（自我測試都有檢查，並與 `scipy.signal.resample_poly` 比對，最大差 9e-16）。

## 八、不等間距與斷線：對齊到共同時間軸

真實世界的感測器資料長這樣：

```
IMU（100 Hz，時間戳抖動）： ●  ● ●   ●  ●● ●  ●   ●  ●        ● ●  ●  ●   ← 中間掉了幾包
GPS（10 Hz）：             ●         ●         ●    ……隧道……    ●         ●
共同時間軸（20 Hz）：       |    |    |    |    |    |    |    |    |    |
```

兩個感測器的時間點完全對不上，沒辦法「逐列合併」。

### 走路邏輯：拆成 4 個動作
1. **清資料**：丟掉 NaN（掉包常被記成 NaN）、依時間排序、重複時間戳只留一筆。
2. **建立共同時間軸**：只取「所有感測器都有資料」的交集
   （起點 = 各起點的最大值、終點 = 各終點的最小值），並對齊到 1/rate 的整數倍（不同批次資料才能直接拼）。
3. **逐點插值**：二分搜尋（`searchsorted`）找左右鄰居 t[i] ≤ t ≤ t[i+1]，
   frac = (t − t[i]) / (t[i+1] − t[i])，y = (1−frac)·x[i] + frac·x[i+1]。
4. **★ 斷線不硬插**：若 t[i+1] − t[i] > **max_gap** → 給 **NaN**；超出資料範圍也給 NaN（不外插）。
   max_gap 預設 = 「正常間隔中位數 × 2.5」（用中位數才不會被掉包本身拉大）。

### 手算（動畫分頁 D 的真實數字）
| 感測器 | 查詢 t | 左鄰居 | 右鄰居 | 間隔 | 判斷 | 結果 |
|---|---|---|---|---|---|---|
| IMU | 1.500 | t[150] = 1.4977 | t[151] = 1.5114 | 0.0137 s ≤ 0.025 | frac = 0.0023/0.0137 = 0.167 | 0.833·x[150] + 0.167·x[151] |
| GPS | 1.500 | 1.129 | 1.934 | 0.805 s > 0.251 | 空洞太大 | **NaN** |

### 為什麼不能硬插？
動畫 STEP 4 的例子：GPS 在隧道裡 0.81 秒沒訊號，硬插 = 一條直線，在 1.53 s 給出 **2.39 m/s**；
但事後才知道車子在隧道裡其實先加速再減速，真實是 **3.16 m/s**。

- 插出來的點**看起來跟真量測一模一樣**，下游（卡爾曼濾波、模型訓練、報表）會把它當真的用。
- 正確做法：**NaN + 遮罩**，讓下游知道「這段沒量到」——卡爾曼濾波就只做預測、不做更新。

> 小技巧：控制系統若不能偷看未來，用 `method='previous'`（因果，抓最後一個 ≤ t 的值）；
> 但同樣要配合 max_gap，不然「保持舊值」保持了 3 秒也是在說謊。

## 九、2D 縮放的半像素對齊坑

### 像素是「方塊」，索引是方塊的「中心」
```
輸入像素 0 的範圍（連續座標）：[0 ────────────── 1)       中心 0.5 ← 這才是「索引 0」
放大 ×4 後切成 4 格：           [0─.25)[.25─.5)[.5─.75)[.75─1)
各格中心（連續座標）：            0.125   0.375   0.625   0.875
換回輸入索引（−0.5）：           −0.375  −0.125  +0.125  +0.375
```

所以公式是三步：**加 0.5（索引 → 連續座標）→ 除以 scale → 減 0.5（連續座標 → 索引）**：

> **src = (dst + 0.5) / scale − 0.5**

### 手算：6×6 → 24×24（×4）

| dst | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| src | **−0.375** | −0.125 | 0.125 | 0.375 | 0.625 | 0.875 | 1.125 | 1.375 |

- **dst = 0 → src = −0.375**：在第 0 個像素中心的**左邊**。雙線性要用 x[−1] 與 x[0]，
  x[−1] 超出邊界 → **clamp 成 x[0]**（邊緣像素往外延伸）→ 結果 = 0.375·x[0] + 0.625·x[0] = x[0]。
- **dst = 5 → src = 0.875**：雙線性權重 (0.125, 0.875)。動畫分頁 C 點 dst(5, 9)：
  src = (0.875, 1.875)，2×2 權重 0.016 / 0.109 / 0.109 / 0.766 乘上 72 / 94 / 255 / 104 → **118.92**。

### ⚠️ align_corners=True 的坑
另一種公式 src = dst·(n_in − 1)/(n_out − 1) 硬把「頭尾像素中心」對齊：

| | 像素中心對齊（False，預設） | align_corners=True |
|---|---|---|
| dst = 0 / 23 對到 | −0.375 / 5.375 | 0 / 5 |
| 實際倍率 | 4 | (24−1)/(6−1) = **4.6** |
| 縮小再放大 | 不會累積位移 | 每來回一次就偏一點 |

- 深度學習前處理（OpenCV / PIL）和模型裡（PyTorch `interpolate`）一邊 True、一邊 False，
  輸出會差半個像素，而且很難查。**除非對方明確要求，一律用像素中心對齊（False）。**
- 忘了 ±0.5、直接寫 src = dst / scale 也是常見錯誤：整張圖往左上偏半格。

### 三種方法的差別（分頁 C 的 6×6 測試圖：漸層 + 亮點 255 + 暗區 10）
| 方法 | 鄰居 | 權重 | 輸出範圍 | 觀感 |
|---|---|---|---|---|
| 最近鄰 | 1 | 四捨五入，1 | 10 ~ 255 | 4×4 方塊、鋸齒 |
| 雙線性 | 2×2 | (1−fy)(1−fx)… | 10 ~ 218.5 | 平滑但糊，亮點被抹開 |
| 雙三次 | 4×4 | wy ⊗ wx（含負值） | **−10.9** ~ 246.7 | 銳利，但暗區旁出現過衝；23 個像素 < 0，存回 uint8 前一定要 clip |

> 2D 權重 = y 方向權重 × x 方向權重（**可分離**），所以實作上先沿 y 做 1D、再沿 x 做 1D，
> 計算量從 K² 降到 2K。縮小超過 2 倍時，雙線性只看 2×2 會混疊——要先模糊或用區域平均（第六節的道理）。

## 十、七個工程小技巧（`engineering_tricks.py`）

### 1. RingBuffer：環形緩衝 + 鏡像雙寫
- **為什麼需要**：「最近 N 筆」天天要用（滑動平均、畫圖、FIR 延遲線）；`list.pop(0)` 每次搬整串 O(N)。
- **怎麼做**：只移動寫入指標 O(1)。★ 配置 **2×容量**，每筆同時寫在 i 與 i+capacity：
  ```
  容量 5，寫入 1~8：   [6 7 8 4 5 | 6 7 8 4 5]   head = 3
                              ^^^^^^^^^ 最近 5 筆 = buf[3:8] = 4 5 6 7 8，永遠是連續切片
  ```
  → 直接回傳 numpy **view**，零複製（示範：`np.shares_memory` = True）。
- **坑**：回傳的是 view，之後再寫入內容會變；要保存請 `.copy()`（程式把 view 設成唯讀防呆）。

### 2. RunningStats：Welford 線上平均 / 變異數
- **為什麼需要**：串流資料不能全存，又要隨時知道平均與標準差。
- **為什麼不用 Σx² − (Σx)²/n**：兩個 ~10¹⁹ 的大數相減，只剩幾十的差，double 的 16 位有效數字全被抵消：

  | 資料 | 天真公式 | Welford |
  |---|---|---|
  | 1e8 + [4, 7, 13, 16] | 29.33 | **30** |
  | 1e9 + [4, 7, 13, 16] | **−170.67**（變異數是負的！） | **30** |
  | 1e9 ± N(0,1) 一萬筆 | 2307.1 | **0.9963** |
- **怎麼做**：只追蹤 mean 與 M2：`delta = x − mean；mean += delta/n；M2 += delta·(x − mean)`，全程只處理小數字。
  `merge()` 可以把兩段統計合併（多執行緒 / 分段計算）。

### 3. SchmittTrigger：遲滯比較器
- **為什麼需要**：訊號在門檻附近帶雜訊，單一門檻會瘋狂來回跳。
- **怎麼做**：拆成 high / low 兩個門檻，中間「維持原狀態」。
  ```
      high ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   往上要超過 high 才 ON
      low  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   往下要低於 low 才 OFF
  ```
  示範：緩慢正弦 + 雜訊，單一門檻切換 **54 次**，Schmitt（±0.3）**4 次**（剛好 2 週期 × 2）。
- **坑**：遲滯帶要比雜訊峰對峰值大；代價是反應延遲。

### 4. Debouncer：去彈跳
- **為什麼需要**：機械接點閉合時會反覆碰撞，一次按鍵讀成好幾次。
- **怎麼做**：新狀態要**連續穩定 N 個樣本**才承認。
  ```
  原始：  00101101111110100000   ← 4 個上升緣（會被算成按 4 次）
  去彈跳：00000000011111111000   ← 只有 1 次（N = 3）
  ```
- **坑**：N × 取樣週期 = 去彈跳時間（通常 5~20 ms）；0/1 訊號用它，類比值用 Schmitt。

### 5. deadband：死區
- **為什麼需要**：搖桿放開讀到 0.03、PID 誤差很小，不想讓致動器為了雜訊一直出力。
- **怎麼做**（半寬 0.1）：

  | x | 0.05 | 0.10 | 0.12 | 0.30 | 1.00 |
  |---|---|---|---|---|---|
  | 硬切（\|x\| ≤ w → 0） | 0 | 0 | **0.12**（突然跳出來） | 0.30 | 1.00 |
  | 連續（sign·(\|x\| − w)，預設） | 0 | 0 | **0.02**（平滑長出來） | 0.20 | 0.90 |
- **坑**：硬切版在邊界有跳躍，控制迴路會在邊界附近抖；連續版讓小訊號增益偏小。

### 6. LinearLUT：查表 + 線性插值（NTC 熱敏電阻）
- **為什麼需要**：NTC 的溫度要算 log，MCU 算不起；或感測器根本沒有公式，只有校正表。
- **怎麼做**：二分搜尋找區間 → 兩點拉直線；表格 x 遞減（越熱 ADC 越小）會自動翻轉。
  10k NTC / B3950、每 10°C 一點：ADC 2048 → 25.08°C（精確 24.99°C），全範圍最大誤差 0.47°C（曲線最彎處，該段把點放密即可）。
- **★ 超出範圍 clamp 並回報**：ADC 4090 → 夾在 −20°C、`out_of_range=True`（多半是**斷線**）；
  ADC 5 → 夾在 100°C（多半是**短路**）。外插只會算出「離譜但看起來合理」的數字。

### 7. Q15 定點數
- **為什麼需要**：沒有浮點單元的 MCU / DSP 用整數表示小數：Q15 = 整數 / 32768，範圍 [−1, 0.99997]。
- **怎麼做**：
  - 轉換：`floor(x·32768 + 0.5)`（四捨五入）再**飽和**到 [−32768, 32767]。
  - 乘法：int32 相乘（Q30）→ **加 1<<14 再右移 15**（四捨五入）→ 飽和。
- **坑**：

  | 情況 | 不處理的後果 | 正確結果 |
  |---|---|---|
  | to_q15(1.0) | 32768 放不下 → 變 −32768（= −1.0，正負顛倒） | 飽和成 32767 |
  | (−1) × (−1) | 右移後 32768 → int16 溢位 | 飽和成 32767 |
  | 0.75 + 0.5 | int16 繞回 = **−0.75** | 飽和成 0.99997 |
  | 直接右移（截斷） | 平均偏差 **−0.4995 LSB**，在 IIR / 積分器裡累積成直流偏移 | 四捨五入後 −0.0004 LSB |

  另外：負數右移在 C（C++20 以前）是「實作定義」，移植時要確認編譯器是算術右移。

## 十一、最容易卡住的疑問

### Q1：上採樣多出來的點，是「新資訊」嗎？
**不是。** 取樣定理說帶限訊號的中間值早就被決定了，上採樣只是把它們**算出來**；
它不會讓你看到原本取樣率裝不下的細節（超過原 Nyquist 的東西本來就沒記到）。
上採樣常見的用途是「讓後面的運算方便」：對齊別的感測器、讓 DAC 後的類比濾波器好設計、畫圖平滑。

### Q2：為什麼我的 FIR 結果整條往右偏？
**群延遲。** 對稱 FIR 的延遲 = (numtaps − 1)/2 個樣本。即時系統只能接受；離線處理要把它扣掉
（`lowpass_aligned`、`upsample_fir` 都已經扣了）。用奇數長度，延遲才是整數、才能精確對齊。

### Q3：為什麼輸出長度是 N·L，不是 (N−1)·L + 1？
兩種約定都有人用。本函式庫跟 `scipy.signal.resample_poly` 一樣用 N·L（第 m 點在時間 m/L），
這樣「上 L 再降 L」長度剛好還原、有理數倍的長度公式 ⌈N·L/M⌉ 也一致。
最後 L−1 點落在 x[N−1] 之後，插值法用 clamp 延伸；動畫只畫 0 ~ N−1 這段（(N−1)·L + 1 點）。

### Q4：FFT 補零這麼準，為什麼不都用它？
它假設訊號**整段是週期的**：頭尾會被當成接在一起。非週期訊號頭尾不連續，就會在兩端出現環繞假影；
而且要整段資料才能算，不適合即時串流。週期訊號（整數週期的測試音、轉一圈的角度）才是它的主場。

### Q5：IMU 100 Hz 要對齊到 20 Hz，直接線性插值可以嗎？
**小心混疊！** 從 100 Hz 取到 20 Hz 本質上是降採樣（÷5），直接插值 = `decimate_naive`，
10 Hz 以上的振動會折進來。正確做法：先低通（`decimate`）或在每個時間窗內平均，再對齊。
「上採樣」低速感測器（GPS 10 Hz → 20 Hz）用線性插值則沒問題。

### Q6：兩個感測器的時鐘本身就不同步呢？
`align_streams` 假設所有時間戳在**同一個時鐘**上。不同裝置要先做時間同步
（硬體 PPS、PTP/NTP、或用已知事件 / 互相關估計時間偏移），否則對得再整齊也是錯的。

### Q7：雙三次為什麼會出現比原圖更亮 / 更暗的值？
權重有負的（見第四節），在亮暗交界附近，加權和會超出原本的範圍（過衝 / ringing）。
分頁 C 的測試圖輸出最小 −10.9（原圖最小是 10）→ 存回 uint8 前一定要 clip 到 0 ~ 255。

## 十三、虛擬碼 + 複雜度

```python
def upsample_fir(x, L, h):                 # h：截止 1/L 的低通，長度奇數
    D = (len(h) - 1) // 2                  # 群延遲
    y = zeros(len(x) * L)
    for p in range(L):                     # L 個相位（polyphase）
        a, b = divmod(p + D, L)
        e = h[b::L]                        # 第 p 個子濾波器
        y[p::L] = convolve(x, e)[a : a + len(x)]   # 直接對原始 x 卷積，不碰插進去的 0
    return y * L                           # 補增益

def decimate(x, M, h):                     # h：截止 1/M（新 Nyquist）
    return lowpass_aligned(x, h)[::M]      # 先抗混疊、扣群延遲，再每 M 取一

def resample_rational(x, L, M):
    g = gcd(L, M); L, M = L // g, M // g   # 160/147
    h = lowpass(cutoff = 1 / max(L, M))
    for i in range(ceil(len(x) * L / M)):  # 只算要留下的點
        q = i * M + D
        base, b = divmod(q, L)             # 第幾個原始樣本、第幾個相位
        y[i] = L * sum(h[b + r*L] * x[base - r] for r in range(K))

def resample_nonuniform(t, x, tq, max_gap):
    i = searchsorted(t, tq) - 1            # 二分搜尋左鄰居
    frac = (tq - t[i]) / (t[i+1] - t[i])
    y = (1 - frac) * x[i] + frac * x[i+1]
    y[(t[i+1] - t[i]) > max_gap] = NaN     # 空洞太大：不插值
    y[(tq < t[0]) | (tq > t[-1])] = NaN    # 不外插
    return y

def resize_bilinear(img, s):
    for each dst (r, c):
        sy = (r + 0.5) / s - 0.5;  sx = (c + 0.5) / s - 0.5     # 像素中心對齊
        y0, x0 = floor(sy), floor(sx);  fy, fx = sy - y0, sx - x0
        out[r, c] = Σ (1−fy | fy) × (1−fx | fx) × img[clamp(y0 | y0+1), clamp(x0 | x0+1)]
```

**複雜度**（N = 輸入長度、K = 每點用到的鄰居數）：

| 函式 | 時間 | 備註 |
|---|---|---|
| ZOH / 線性 / 三次 上採樣 | O(N·L·K)，K = 1 / 2 / 4 | |
| `upsample_fir`（polyphase） | O(N·L · numtaps/L) = O(N·numtaps) | 直接插零再卷積是 O(N·L·numtaps)，慢 L 倍 |
| `upsample_fft` | O(N·L · log(N·L)) | 要整段資料 |
| `decimate` | O(N·numtaps) | 只算留下的點可再省 M 倍（`resample_rational(x, 1, M)`） |
| `resample_rational` | O(N·L/M · numtaps/L) | 每個輸出點 ⌈numtaps/L⌉ 次乘法 |
| `resample_nonuniform` | O(Q·log N) | Q 個查詢點，每個二分搜尋 |
| `resize`（可分離） | O(H'·W·K + H'·W'·K) | 不可分離的 2D 做法是 O(H'·W'·K²) |

### 最後再濃縮成三句話
1. **設計思路**：上採樣 = 插零 + 低通 + ×L，降採樣 = 低通 + 每 M 取一；有理數倍是兩者合體，不等間距與 2D 縮放是同一套「鄰居 × 權重」的推廣。
2. **計算邏輯**：每個新點 = 一組鄰居 × 一組權重（核心）；核心越接近理想低通越準，polyphase 讓長核心也便宜。
3. **工程鐵律**：時間軸要對齊（群延遲、半像素、整數格點），裝不下的頻率先濾掉，沒量到就給 NaN——絕不捏造資料。
