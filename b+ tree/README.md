# B+ 樹視覺化教學(PyQt6)

用 Qt6 製作的 B+ 樹互動教學工具:每一個操作都拆解成一連串動畫步驟,
配合中文解說與顏色標記,完整呈現 B+ 樹的走訪、分裂、借鍵、合併過程。

![畫面截圖](shots/02_overflow.png)

## 執行方式

```bash
pip install -r requirements.txt
python main.py
```

需求:Python 3.9+、PyQt6。

## 功能

| 操作 | 動畫呈現的內容 |
|---|---|
| 插入 | 由根往下比較索引鍵 → 放入葉節點 → 溢位偵測 → 葉節點/內部節點分裂 → 必要時長出新根(樹高 +1) |
| 刪除 | 找到葉節點 → 移除鍵 → 更新內部索引副本 → 不足(underflow)偵測 → 向兄弟借鍵(旋轉)或合併 → 必要時根塌縮(樹高 −1) |
| 搜尋 | 完整走訪路徑,逐步顯示每一次索引鍵比較 |
| 範圍查詢 | 先定位起點葉節點,再沿「葉節點鏈結串列」往右掃描 —— 展示 B+ 樹相對 B 樹的核心優勢 |
| 隨機插入 / 範例建樹 | 一鍵產生教學示範(範例會觸發多次分裂與長高) |
| 階數切換 | 3 / 4 / 5 / 6 階,既有的鍵會自動重建,右側規則面板同步更新 |

## 操作介面

- **數值輸入**:支援一次多個(例:`5, 17, 42`),按 Enter 等同「插入」。
- **播放控制**:播放/暫停、上一步/下一步、跳到最前/最後、速度 25%~300%。
- **步驟列表**:右側列出每一步解說,點擊任一步可直接跳轉(方便上課講解)。
- **畫布**:滑鼠滾輪縮放、按住拖曳平移;「自動縮放」會在每一步後自動置中。
- **顏色圖例 / 規則面板**:右下角隨時對照目前階數的容量規則。

## 本實作採用的 B+ 樹定義(階數 m = 內部節點最大子節點數)

- 內部節點:最多 `m-1` 個鍵、`m` 個子節點;非根節點至少 `⌈m/2⌉` 個子節點。
- 葉節點:鍵數 `⌈(m-1)/2⌉ ~ m-1`,彼此以鏈結串列由小到大相連。
- 資料一律存於葉節點;內部節點的鍵只是導引搜尋的「路標」。
- 葉節點分裂時,右半的最小鍵「複製」上推;內部節點分裂時,中間鍵「搬移」上推。
- 相等的鍵往右子樹走(`key ≥ 索引鍵` → 右邊)。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `bplus_tree.py` | B+ 樹資料結構(無 Qt 相依),每個操作會記錄「快照 + 解說 + 強調標記」的教學步驟 |
| `tree_view.py` | QGraphicsView 畫布:樹狀佈局、節點繪製、快照間的補間動畫(移動/淡入/淡出、連線即時重算) |
| `main.py` | 主視窗:操作列、解說橫幅、步驟列表、播放器、規則面板 |
| `test_bplus.py` | 隨機模糊測試:5 種階數 × 2500 次操作,驗證所有 B+ 樹不變量 |
| `smoke_test.py` | GUI 煙霧測試(offscreen):跑完整流程並輸出 `shots/` 截圖 |

## 測試

python test_bplus.py   # 資料結構不變量(全部通過才會印 ALL TESTS PASSED)
