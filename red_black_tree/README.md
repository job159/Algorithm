# 資料結構互動教學（BST / AVL / 紅黑樹，Qt6 / PySide6）

一個用 **Qt6（PySide6）** 寫的可視化教學工具，上方選單可切換三種樹：
**二元搜尋樹（BST）**、**AVL 樹**、**紅黑樹（Red-Black Tree）**。
插入、刪除、搜尋都會**逐步播放並用中文解說**，旋轉、重新著色都有平滑動畫，
適合上課或自學。

| 紅黑樹（紅/黑） | AVL（綠，顯示平衡因子） | BST 依序插入 → 退化成鏈狀 |

## 為什麼三種一起教？（學習重點）

同樣「依序插入 1..10」，三種樹的結果天差地遠：

| 樹 | 結果 | 樹高 |
| --- | --- | --- |
| 二元搜尋樹 | 沒有平衡機制 → **退化成鏈狀** | **10**（O(n)） |
| 紅黑樹 | 旋轉 + 重新著色自動平衡 | **5**（O(log n)，鬆平衡） |
| AVL 樹 | 旋轉維持嚴格平衡 | **4**（最矮） |

選單的「範例」裡有三個「依序插入 1..10」示範，可直接做出這個對比，
左下角的**樹高**即時反映差異。這正是為什麼工程上需要自平衡樹。

## 三種樹的重點

- **二元搜尋樹（藍）**：最基本，左 ＜ 節點 ＜ 右；但最壞情況會退化。
- **AVL 樹（綠）**：嚴格平衡，每個節點的**平衡因子**（左高 − 右高）只能是 −1/0/+1；
  節點上方的徽章就是平衡因子，**變成 ±2（紅色）就觸發旋轉**（LL/RR 單旋、LR/RL 雙旋）。查詢最快。
- **紅黑樹（紅/黑）**：用顏色規則做「鬆」平衡，插入/刪除的旋轉次數較少，是實務上最常用的平衡樹。

## 功能

- **三種資料結構**：選單一鍵切換，節點顏色不同（BST 藍、AVL 綠、紅黑樹紅/黑）。
- **逐步播放**：每個操作拆成一格一格，附中文說明（例如「右右（RR）情況：對 6 做一次左旋即可」）。
- **平滑動畫**：旋轉時節點滑到新位置、新節點長出來、被刪節點縮掉。
- **教學連動**：紅黑樹高亮當下維護的性質；AVL 顯示每個節點的平衡因子（±2 變紅警示）。
- **NIL／空葉節點**：可勾選顯示黑色 `NIL` 方塊，方便講解葉節點與黑高。
- **即時狀態**：節點數、**樹高**、黑高（紅黑樹）、中序走訪、自動驗證（✓／✗）。
- **正確性**：核心演算法採 CLRS／標準教科書版本，三種樹皆通過大量隨機測試。

## 安裝與執行

需要 Python 3.9+ 與 PySide6：

```powershell
pip install PySide6
python main.py
```

## 選單

| 選單 | 項目 |
| --- | --- |
| 資料結構(D) | 紅黑樹／二元搜尋樹／AVL 樹（切換模式） |
| 範例(E) | 建立範例樹、**BST 退化示範**、**AVL 依序插入 1..10**、**紅黑樹依序插入 1..10**、清空 |
| 說明(H) | 操作說明、關於 |

## 操作說明

- 輸入整數後按 **插入／刪除／搜尋**（或在輸入框按 Enter 直接插入）。
- 逐步播放：◀ 上一步、▶ 播放／⏸ 暫停、下一步 ▶、速度滑桿。
- **鍵盤**：`空白鍵` 播放／暫停、`←` `→` 切換步驟。
- **滑鼠**：滾輪縮放、拖曳平移畫布。

## 檔案結構

| 檔案 | 內容 |
| --- | --- |
| `bst.py` | 二元搜尋樹核心邏輯（含逐步記錄、自我測試） |
| `avl.py` | AVL 樹核心邏輯（含平衡因子、LL/LR/RL/RR 旋轉、自我測試） |
| `rbtree.py` | 紅黑樹核心邏輯（CLRS 版本，含 NIL 哨兵與逐步記錄、自我測試） |
| `rbview.py` | 視覺化畫布：排版、節點圖元、平衡因子徽章、位移動畫（`QGraphicsView`） |
| `main.py` | 主視窗：選單列、操作按鈕、逐步控制、解說、性質、狀態列 |

三個核心模組都採同一套「快照格式」，所以共用同一個畫布。

## 驗證核心正確性

三個核心模組都可單獨執行做隨機測試：

```powershell
python bst.py     # 隨機操作維持 BST 性質，依序插入會退化成鏈狀
python avl.py     # 隨機操作維持 AVL 平衡，依序插入仍是 O(log n)
python rbtree.py  # 40 輪隨機插入/刪除，全程滿足紅黑五大性質
```
