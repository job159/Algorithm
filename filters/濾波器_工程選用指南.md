# 工程常用濾波器：先看雜訊，再挑濾波器

> **一句話總結**：濾波就是「用過去的點投票，算出一個比較可信的值」。
> 投票的人越多越平滑，但結果代表的是「過去」→ **越平滑就越落後**，這是所有濾波器逃不掉的取捨。
> 雜訊也不只一種：**白噪用平均、尖峰用中位數、移動中的訊號要加入預測、會漂的感測器找另一個感測器互補**。

這份文件是 `filter_lessons_pyqt6.py`（六堂互動課）的文字版。
**建議順序**：先跑互動課、一章一章看 → 再看這份文件的對應章節 → 最後讀 `filters.py`（工程用的串流式實作，每個類別都有 STEP 1、STEP 2… 的設計說明）。

```bash
python filter_lessons_pyqt6.py
```

互動課的顏色固定：**灰點 = 原始量測**、**深灰虛線 = 真值**、**藍 = 這一章的主角**、**橘 = 對照組**、**琥珀 = 窗口 / 權重**。

## 第 1 章　濾波在做什麼？用過去幾個點「投票」

**問題**：量測一下高、一下低（白噪）。想要一條平滑的線。

**最直覺的做法：移動平均（MA）** —— 輸出 = 最近 N 個點的平均。

```
   量測：  2   4   3   9   4   3   3
           └───┴───┘                    → (2+4+3)/3 = 3.00
               └───┴───┘                → (4+3+9)/3 = 5.33
                   └───┴───┘            → (3+9+4)/3 = 5.33
   窗口 N = 3，每個點的「發言權」都是 1/3
```

| k | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 量測 | 2 | 4 | 3 | **9** | 4 | 3 | 3 |
| MA（N=3） | 2 | 3 | 3 | 5.33 | 5.33 | 5.33 | 3.33 |

（前兩點窗口還沒滿：有幾點就除以幾，不要硬除以 3，否則開頭會從 0 爬上來。）

**好處**：N 個隨機誤差一正一負會互相抵消，抖動剩下約 **1/√N**。

**代價**：平均值代表的是窗口「**中間**」那個時間 → 落後 **(N − 1)/2 點**。

| N | 剩下的抖動 | 落後 |
|---|---|---|
| 1 | 100%（沒濾） | 0 點 |
| 5 | 45% | 2 點 |
| 15 | 26% | 7 點 |
| 31 | 18% | 15 點 |

```
   抖動
   100% ●
        │ ╲
        │   ╲        這條線以下「到不了」
    26% │      ●──── N = 15           —— 沒有白吃的午餐：
        │          ─────────●── N = 31    想更平滑，就得更落後
        └────────────────────────── 落後
```

> 💡 這是整套課最重要的一張圖。第 2 章的 EMA 也落在**同一條曲線**上。想跳出這條線，只能加入「模型」（第 4 章）。

**實作**（`filters.py` 的 `MovingAverage`）：環形緩衝 + 累加和，每點只做 1 加 1 減 1 除，跟 N 多大無關；每隔一段時間用 `math.fsum` 重算累加和，清掉浮點誤差。

## 第 2 章　只記一個數也能平滑：EMA

**問題**：MA 要存 N 個點，MCU 的記憶體很貴。

**EMA（指數移動平均 = 一階低通）**：只記「上一次的輸出」，每次把新量測混一點進去。

```
   y = α · x  +  (1 − α) · y前
       ─────     ─────────────
       新量測      上一次的輸出
```

手算（α = 0.5）：

| k | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 量測 x | 2 | 4 | 3 | **9** | 4 | 3 | 3 |
| EMA | 2 | 0.5×4+0.5×2 = **3** | 3 | **6** | 5 | 4 | 3.5 |

**為什麼叫「指數」？** 把公式展開，過去第 m 點的權重是 α(1−α)^m：越舊越小、一路滑下去，但永遠不會歸零。

```
   權重   MA（N=5）：▇ ▇ ▇ ▇ ▇           每點一樣大，窗口外 0
          EMA     ：▁ ▂ ▃ ▅ ▇           越新越大，越舊越小
                    ←舊        新→
```

**取捨跟 MA 幾乎一樣**：落後約 **(1−α)/α 點**；α = 0.15 時落後 5.7 點、抖動剩 28%，跟 N = 12 的 MA 差不多。
EMA 贏的不是效果，是**成本**：記憶體 1 個數、計算 1 乘 1 加。

**跟 RC 電路的關係**：α = dt / (RC + dt)，RC = 1 / (2π·fc)。所以可以直接用截止頻率 fc 來設定（`EMA.from_cutoff(fc, dt)`）。

## 第 3 章　遇到尖峰：平均會被拖累，中位數不會

**問題**：偶爾一個瘋狂的值（ADC 讀錯、超音波打到雜物、通訊掉包）。

看上面兩張表的第 3～5 點：一個 **9** 讓 MA 連續三點變成 5.33、EMA 跳到 6 —— **平均是「大家一起扛」，一個瘋子就能把結果拉走。**

**中位數濾波**：把窗口排隊，取正中間那一個。

```
   窗口 [3, 9, 4]  → 排隊 [3, 4, 9] → 取中間 = 4      ← 9 被擠到最邊邊，碰不到中間
```

| k | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 量測 | 2 | 4 | 3 | **9** | 4 | 3 | 3 |
| MA（N=3） | 2 | 3 | 3 | 5.33 | 5.33 | 5.33 | 3.33 |
| **中位數（N=3）** | 2 | 3 | 3 | **4** | **4** | **4** | 3 |

互動課的尖峰訊號（N = 7）：原始誤差 0.424 → MA 只降到 0.170 → **中位數 0.065**。

**另一個好處：保留邊緣。** 步階前後各是一群相近的值；窗口過半換成新值時，中位數直接跳過去，不會像平均那樣變成斜坡。

**注意**：
- 能擋住的最長連續尖峰 = (N − 1)/2 點。N = 3 時，連續兩個尖峰就擋不住。
- 對純白噪，中位數的平滑效率比平均差 → 只有在有尖峰時才用它。
- **Hampel**（`filters.py`）：先用「中位數 + MAD」判斷這點是不是離群值，**是才換掉、不是就原值照用** —— 適合資料清洗、或接在其他濾波器前面。

## 第 4 章　訊號在移動：平均一定落後，α-β 會預測

**問題**：目標在等速移動（滑台、車子、旋轉的編碼器）。平均類濾波器會**一直落後一截**：

```
   落後量 = 移動速度 × 延遲
```

互動課裡（α = 0.12）：等速移動那一段，EMA 的平均誤差 **−0.164**（一直在真值下面），α-β 只有 **+0.011**。

**α-β 濾波**：多記一個「速度」，每一點做三件事：

```
   ① 預測：x⁻ = x + v·dt          「照目前的速度，現在應該走到這」
   ② 殘差：r  = z − x⁻            「量測跟預測差多少」
   ③ 修正：x  = x⁻ + α·r          位置往量測修正 α 這麼多
           v  = v + (β/dt)·r      速度也順便修正
```

因為先用速度「往前推」，等速移動時預測本來就對，殘差平均是 0 → **沒有落後**。

**代價**：
- 有「模型」就有「模型錯的時候」：滑台突然停下，α-β 以為還在動，會**稍微衝過頭**。
- 同樣的 α，α-β 靜止時會比 EMA 抖一點（互動課：0.036 vs 0.027）。

**參數**：先選 α（0.05～0.5），β 用經驗公式 β = α²/(2 − α)；有雜訊統計時可用 `alpha_beta_from_tracking_index` 算最佳值。

> 💡 **α-β 就是「增益固定」的卡爾曼濾波**。卡爾曼會每一步自己算增益、還能融合多個感測器 → 見 `kalman_filter/` 資料夾的六堂課（第 2、4 章對應這裡）。

## 第 5 章　兩個感測器互補：陀螺儀 + 加速度計

**問題**：想知道傾斜角（平衡車、無人機、手機）。

| 感測器 | 短時間 | 長時間 |
|---|---|---|
| **陀螺儀**（量角速度，積分得角度） | ✓ 很準、很平滑、反應快 | ✗ 一點點偏差積分起來會越漂越遠 |
| **加速度計**（用重力方向算角度） | ✗ 振動讓它很吵 | ✓ 平均起來是準的 |

兩個的優缺點剛好互補 → **快的變化聽陀螺儀，慢的趨勢聽加速度計**：

```
   θ = α · (θ前 + ω·dt)  +  (1 − α) · a
       ─────────────────     ──────────
       陀螺儀往前推一步        每點往加速度計「拉一點點」

   α = τ / (τ + dt)：比 τ 快的變化信陀螺儀，比 τ 慢的信加速度計
```

互動課的數字（整段誤差）：

| 方法 | 誤差 |
|---|---|
| 只用加速度計 | 5.9°（很吵） |
| 只用陀螺儀積分 | 12.7°（漂走了，最後偏了快 20°） |
| **互補濾波（τ = 1 秒）** | **2.8°**，而且幾乎沒有延遲 |
| 互補濾波（τ = 8 秒） | 6.5°（太信陀螺儀，漂移拉不回來） |

**為什麼叫「互補」？** 陀螺儀那條是高通、加速度計那條是低通，兩個加起來剛好 = 1 → 真實的角度不會被扭曲。

## 第 6 章　怎麼選？

```
                         ┌─ 一直小小地抖（白噪）──────────→ 移動平均 / EMA        （第 1、2 章）
                         │
   先看你的雜訊 ──────── ├─ 偶爾一個瘋狂的值（尖峰）──────→ 中位數 / Hampel      （第 3 章）
   長什麼樣？            │
                         ├─ 訊號在移動、不能落後 ─────────→ α-β → 卡爾曼         （第 4 章）
                         │
                         └─ 兩個感測器：一個漂、一個吵 ───→ 互補濾波             （第 5 章）
```

| 濾波器 | 一句話 | 落後 | 去尖峰 | 記憶體 | 最常用在 |
|---|---|---|---|---|---|
| 移動平均 | 最近 N 點平均 | (N−1)/2 點 | ✗ 會被拉走 | N 個數 | 顯示讀值、資料記錄 |
| EMA | 新舊照比例混合 | (1−α)/α 點 | ✗ 拖尾巴 | 1 個數 | MCU 感測器平滑 |
| 中位數 | 排隊取中間 | (N−1)/2 點 | ✓ 最強 | N 個數 | ADC 錯讀、測距跳點 |
| Hampel | 判斷是壞點才換 | 0 | ✓ | N 個數 | 資料清洗、前處理 |
| α-β | 預測 + 修正（固定增益） | 等速時 0 | ✗ 先過 Hampel | 2 個數 | 位置 → 速度、目標追蹤 |
| 互補濾波 | 快的信 A、慢的信 B | ≈ 0 | ✗ | 1 個數 | IMU 姿態角 |
| 卡爾曼 | 增益會自己算的 α-β | 依模型 | ✓ 加閘門 | 矩陣 | 多感測器融合、導航 |

**進階**（`filters.py` 裡也有，互動課不展開）：

| 需求 | 用這個 |
|---|---|
| 要精準的頻率規格（例如「50 Hz 以上要衰減 40 dB」） | **Biquad 巴特沃斯**，可串成高階 |
| 靜止時要很穩、動起來要跟得上（滑鼠、手勢、VR） | **One Euro**：速度越快，截止頻率自動越高 |
| 不怕雜訊、只是不准變化太快（馬達命令、燈光漸變） | **斜率限制** |

**工程實務的順序**：**先去尖峰**（中位數 / Hampel）→ **再平滑**（EMA / MA）→ 要估速度或融合多個感測器，才上 α-β / 卡爾曼。

## 實作時的眉角

| 眉角 | 說明 |
|---|---|
| **暖機** | 第一筆直接當輸出（EMA）、窗口沒滿就有幾點除幾點（MA）。不要從 0 開始，否則開機會看到假的爬升。 |
| **單位** | fc 用 Hz、dt 用秒、ω 用「每秒」。α = dt/(RC+dt) 裡 dt 一定要用**實際量到的**取樣間隔。 |
| **整數溢位** | MCU 上用整數累加和時，算好位寬：N 個 12-bit ADC 值相加需要 12 + log₂N 位元。 |
| **先濾波再微分** | 對吵雜的位置直接相減求速度，雜訊會被放大好幾倍；要速度就用 α-β 或先平滑再差分。 |
| **控制迴路** | 濾波的延遲 = 相位落後，會讓 PID 迴路變得容易振盪。放進迴路前先算好延遲。 |
| **尖峰先處理** | EMA 遇到尖峰會拖出一條指數尾巴；α-β 遇到尖峰速度會被帶歪 → 前面先接 Hampel。 |

---

### 最後濃縮成三句話
1. **濾波 = 用過去的點投票**：投票的人越多越平滑，但結果代表的是「過去」→ 一定落後。
2. **雜訊不只一種**：白噪用平均、尖峰用中位數、會漂的感測器靠另一個感測器互補。
3. **想要又平滑又不落後**，就得加入「模型」（α-β、卡爾曼）—— 用預測補上延遲，代價是模型錯的時候會衝過頭。
